# Recovery Bot

Recovery Bot é um aplicativo(mais conhecido como "bot") na plataforma Discord, cuja funcionalidade é criar sessões de WhatsApp e fazer o envio de mensagens automaticamente.

## Por que não open source?

O projeto será monetizado muito em breve, não viabilizando disponibilizar open source de início.
