# Recovery-Bot

Recovery Bot é um aplicativo(mais conhecido como "bot") na plataforma Discord, cuja funcionalidade é criar sesssoes de whatsapp e fazer o envio de mensagens automaticamente.

## Por que nao opensource ?

O projeto será monetizado muito em breve, nao viabilizando disponibilizar opensource de inicio.
